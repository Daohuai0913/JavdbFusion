# JavdbFusion

JavdbFusion 是面向 JAVDB 的 Tampermonkey 用户脚本，融合 Emby 风格界面、Emby/Jellyfin 媒体库联动、预告片播放和磁力工具。

## 功能

- **界面与导航**：Emby 风格皮肤、液态玻璃样式、导航增强、卡片布局、收藏管理和 TOP250/热播榜入口。
- **Emby / Jellyfin 联动**：配置多个媒体服务器、同步本地媒体索引，在影片详情与列表中显示入库状态；列表卡片支持预告片预览和媒体库搜索/播放。
- **预告片**：整合 JAVDB 官方预告片、DMM/FANZA、厂商直链及其他来源，并提供内嵌播放器。
- **磁力工具**：复制磁力链接、qBittorrent 和 115 操作、磁力聚合搜索及资源信息辅助。
- **页面增强**：评论与清单加载、演员/影片信息、筛选、快捷搜索和无缝翻页等功能。

## 安装

1. 在 Chrome、Edge 或 Firefox 安装 Tampermonkey。
2. 从项目的 **Releases** 下载 `JavdbFusion.user.js`，或打开项目中的脚本文件并选择由 Tampermonkey 安装。
3. 安装后访问 JAVDB，打开脚本设置并按需启用功能。

> 如果同时启用了另一款会重做 JAVDB 页面样式的用户脚本，可能出现界面冲突；遇到问题时请先停用重复的皮肤脚本。

## 配置

### Emby / Jellyfin

打开脚本的「融合扩展设置」→「媒体库」→「添加服务器」，选择服务器类型并填写服务器地址和 API Key。点击「测试连接」后可同步索引。API Key 请在自己的媒体服务器中创建，不要提交到仓库或公开分享。

### 其他服务

qBittorrent、115、磁力搜索等连接信息均在脚本设置中填写。账号、密码、API Key 和令牌由用户脚本管理器在本机保存；不要将个人配置导出并上传。

## 权限与隐私

- 脚本需要在 JAVDB 页面运行，并通过用户脚本管理器的请求接口连接脚本功能所需的站点、已配置的媒体服务器及相关服务。
- 连接媒体服务器时，浏览器会向你配置的服务器发送影片番号查询或索引请求，并使用你填写的 API Key 鉴权。
- 不要把带有个人 API Key、密码、登录令牌、内网地址或个人媒体信息的配置文件、日志、截图发布到公开仓库。

## 常见问题

- **媒体库按钮显示搜索而不是播放**：确认服务器已启用、API Key 有效，并在设置中同步索引；列表页也会对屏幕附近的影片按需查询。
- **Jellyfin 详情链接无法打开**：先在媒体库设置中测试连接并确认服务器地址可从当前浏览器访问。
- **更新后界面没有变化**：在 Tampermonkey 中确认脚本版本已更新，然后刷新 JAVDB 页面。
